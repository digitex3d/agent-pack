# Security Policy

## Supported versions

agent-pack is pre-1.0. Security fixes land in the latest minor release only.

| Version | Supported |
|---|---|
| latest `0.x` minor | yes |
| older | no — upgrade to the latest release |

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through GitHub's private vulnerability reporting: on [github.com/digitex3d/agent-pack](https://github.com/digitex3d/agent-pack), open **Security → Report a vulnerability**. Include what is affected, how to reproduce it and the impact you see.

You will get an acknowledgement once the report has been read; the fix and its disclosure are coordinated with you through the advisory.
